# 요구사항

## 공통 요구사항

- 프로젝트는 완성형 확장 플랫폼을 목표로 한다.
- 기계, PCB, 펌웨어 설계는 서로의 제약을 반영하여 진행한다.
- 전체 크기, 중량, 링크 길이, 배터리 사양은 계산과 검증 후 확정한다.
- 약 1시간 동작 가능한 배터리를 목표로 하되, 배터리 무게가 서보 토크 한계를 넘지 않도록 한다.

## 기계 요구사항

- AutoCAD와 Onshape를 사용한다.
- 바디 재질은 Creality Hyper PLA Black을 기준으로 한다.
- 회전부에는 NSK 베어링 사용을 검토한다.
- 조립부에는 황동 인서트를 사용한다.
- MG996R 최대 사양의 20% 수준을 기준으로 토크 설계를 검토한다.

## PCB 요구사항

- EasyEDA Pro를 주 설계 도구로 사용한다.
- SKIDL은 회로 구조화와 반복 회로 작성에 활용한다.
- 외부 배터리만 연결하면 동작하는 단일 PCB를 목표로 한다.
- BEC, 컨버터 등 외장 전원 모듈 없이 PCB에 전원 변환과 분배를 통합한다.
- 전원부 단자는 KF301을 기준으로 한다.
- 신호부 커넥터는 Molex 5267을 기준으로 한다.

## 펌웨어 요구사항

- STM32F103C8T6 Blue Pill을 기준으로 한다.
- STM32CubeMX와 VS Code 환경을 사용한다.
- 12개 서보 제어 구조를 설계한다.
- 하드웨어 검증용 펌웨어와 보행 제어 펌웨어를 단계적으로 분리한다.
