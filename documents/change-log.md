# 변경 기록

## 2026-05-18

- 프로젝트 목표를 직접 설계 가능한 확장형 학습 플랫폼으로 정의했다.
- 프로젝트 범위를 MVP가 아닌 완성형 로봇 개로 정의했다.
- 1차 완료 기준을 전원/구동 안정성을 우선 반영한 확장 플랫폼형 완성 로봇 개로 정했다.
- 배터리는 특정 모델을 고정하지 않고, 약 1시간 동작 시간과 무게 제한을 기준으로 계산 후 선정하기로 했다.
- 전체 크기와 무게는 서보 토크, 링크 길이, 배터리 후보, 예상 중량 계산 후 확정하기로 했다.
- 폴더명과 파일명은 영어로, `.md` 문서 본문은 한국어로 작성하기로 했다.
- `pcb-design/skidl/main.py`를 SKIDL 기반 PCB 설계 자동화 진입점으로 정했다.
- SKIDL 코드는 전원부, MCU, 서보 커넥터, 확장 포트를 객체지향 블록으로 나누어 설계하기로 했다.
