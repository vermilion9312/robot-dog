# 로봇 개 프로젝트 마스터 기획서

## 프로젝트 목표

이 프로젝트는 기계 설계, PCB 설계, 펌웨어 설계를 직접 수행하는 확장형 학습 플랫폼을 목표로 한다. 단순 MVP가 아니라 완성형 로봇 개를 기준으로 설계하며, 이후 센서, 통신, 추가 모듈을 확장할 수 있도록 기계 공간, 전원 여유, 펌웨어 구조를 처음부터 고려한다.

## 기본 사양

- MCU: STM32F103C8T6 Blue Pill 1개
- 서보 모터: MG996R 12개
- 전원: 외부 배터리
- 기계 설계 도구: AutoCAD, Onshape
- PCB 설계 도구: EasyEDA Pro, SKIDL
- 펌웨어 개발 환경: STM32CubeMX, VS Code

## 완료 기준

완성형 로봇 개의 1차 완료 기준은 다음과 같다.

- MG996R 서보 12개 기반의 4족 보행 구조를 갖춘다.
- 외부 배터리만 연결하면 동작하는 단일 PCB 전원/제어 구조를 갖춘다.
- 약 1시간 동작 가능한 배터리 후보를 선정하고 검증한다.
- 배터리 무게와 서보 토크 한계를 고려하여 크기와 중량을 산정한다.
- 전원/구동 안정성을 최우선 확장 요구사항으로 반영한다.
- 센서, 통신, 추가 모듈 장착 여유를 확보한다.

## 프로젝트 폴더

- `documents/`: 마스터 기획서, 요구사항, 변경 기록, 설계 결정 기록
- `mechanical-design/`: 기계 설계 요구사항, 토크/링크 계산, CAD 산출물
- `pcb-design/`: PCB 요구사항, 전원 시스템, 커넥터, EasyEDA/SKIDL 산출물
- `firmware-design/`: 펌웨어 요구사항, 구조 설계, CubeMX 설정, 소스 코드, 테스트
